# Event Management System

A modern, responsive event management website with user authentication and role-based access control.

## Features

### User Roles
1. **Admin Users**
   - Can add new events
   - Can delete events
   - Full access to all features

2. **Normal Users**
   - Can view all events
   - Can view event details
   - Cannot modify events

### Main Features
- **Authentication System**: Secure login for both admin and normal users
- **Today's Events**: View all events scheduled for today
- **All Events**: Browse all upcoming events
- **Event Details**: Click on any event to see full details
- **Event Categories**: Events categorized as Conference, Workshop, Seminar, Meeting, Social, or Assessment
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Beautiful UI**: Modern gradient design with smooth animations

## How to Use

1. Open `index.html` in your web browser
2. Login with one of the demo credentials
3. Browse today's events and all upcoming events
4. Click on any event card to view full details
5. If logged in as admin, you can:
   - Add new events using the "Add New Event" button
   - Delete events by clicking the × button on event cards
